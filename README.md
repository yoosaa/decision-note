# decision-note

意思決定を整理するための比較メモアプリです。  
迷っているテーマに対して複数の選択肢を並べ、メリット・デメリット・評価軸ごとのスコアを入力しながら、判断材料を見える形に整理できます。

## Features

- テーマごとの意思決定メモ作成
- 選択肢の追加・編集・削除
- メリット / デメリットの整理
- 評価軸ごとのスコア入力
- 比較結果の可視化
- 保存済みメモの一覧表示
- 詳細表示・編集・削除

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Vitest

## Getting Started

依存関係をインストールします。

```bash
pnpm install
```
